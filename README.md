# Mäx — legal pages

The two public URLs App Store Connect requires for the iPhone app **Mäx**:

| Page | URL | App Store Connect field |
|---|---|---|
| Support | https://angelsol299.github.io/max-legal/ | Support URL |
| Privacy policy | https://angelsol299.github.io/max-legal/privacy.html | Privacy Policy URL |

This repository is public **only** so GitHub Pages can serve these two pages.
The app source is private and lives elsewhere.

No web fonts, no analytics, no third-party requests — an app that claims to
collect nothing should not have a privacy policy that phones out to render
itself.

Keep `privacy.html` in step with `store/privacy-policy.md` in the app repo, and
with the summary shown in-app under Einstellungen → Datenschutz & Lizenzen.
